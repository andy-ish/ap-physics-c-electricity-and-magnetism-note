# Draw Circuits

直接编写可编辑、独立可用的 SVG，保持本笔记库现有电路图的视觉风格。用户指定的元件、拓扑、标注、开关状态和保存位置优先于以下默认约定。

## 本地样式来源

本技能位于笔记库的 `.agents/skills/draw-circuits/`。从技能位置向上定位包含 `AGENTS.md` 和 `附件/` 的笔记库根目录，不依赖当前工作目录，不写死用户电脑的绝对路径。

- 元件来源：[附件/电子元件](../../../附件/电子元件/)。先列出实际文件，按需读取所用 SVG；不修改元件库。
- 可按任务选择一个例图参考布局：[串联电路](../../../附件/两个电阻串联电路.svg)、[并联电路](../../../附件/两个电阻并联电路.svg)、[非理想电源](../../../附件/非理想电源.svg)。例图是参考，不是固定模板或必须照搬的元件清单。
- 直接内联所需元件的 `path`、`circle` 等矢量几何，避免外部文件引用、外部字体或网络依赖。优先保留原始几何，通过分组平移或旋转布局。
- 元件库没有所需符号时，按相同线条风格绘制标准电路符号；只有符号或接法存在影响物理含义的歧义时才澄清。

## 视觉约定

- 透明背景，不添加覆盖画布的底色矩形。
- 导线和元件统一使用 `stroke="#000000"`、`stroke-width="2"`、`stroke-linecap="round"`、`stroke-linejoin="round"`、`fill="none"`。
- 电阻使用元件库中的锯齿形符号；电源沿用长短极板符号，长线端为正极。
- 真实连接的分支节点可用半径 `3` 的黑色实心圆；外部端子可用半径 `5` 的空心圆。交叉但不相连的导线避免使用会误认成节点的画法。
- 标注默认使用黑色、`Arial, Helvetica, sans-serif`、`font-size="22"`、`text-anchor="middle"`，保持普通字重。标注与符号、导线之间留出空隙。
- 严格保留用户要求的标注文字、大小写和编号。未指定时可沿用 `R1`、`R2`、`Switch`、`Battery`；多个开关需要区分时，可用 `Switch0` 表示总开关，`Switch1`、`Switch2` 表示支路开关。
- 优先使用水平、竖直导线与整齐的支路间距，避免无意义的折线和绕行。无需装饰、渐变、阴影或立体效果。
- 画布随内容调整；简单电路可参考宽 `720`、高 `360–500` 的现有图，不能为固定尺寸压缩标签或截断内容。

## 绘制与物理含义

先明确元件数量、节点关系和用户要求的标注，再安排坐标。未指定开关状态时，可沿用现有图的断开符号，并在图的描述和交付说明中写明状态；不擅自增加开关、负载或其他元件。

现有 `resistor.svg`、`battery.svg`、`switch-open.svg` 使用 `160 × 96` 的坐标系，左右引线端点为 `(8, 48)` 与 `(152, 48)`。若放置为 `translate(tx ty)`，端点变为 `(tx+8, ty+48)` 与 `(tx+152, ty+48)`，导线必须准确接到这些端点。其他元件先读取实际端口。旋转元件时同步换算端口位置，文字另设分组以保持正向。

导线在元件的端口处结束，不得额外画一条贯穿电阻、电源极板或开关间隙的直线。优先保持符号原尺寸；确需缩放时保持整张图的线宽一致。

按当前请求应用相关约定：

- **串联**：元件依次位于同一支路；不添加绕过元件的旁路。
- **并联**：各支路连接同一对公共节点，每个支路的开关与本支路元件串联。要求总开关时，将其放在分流前或汇流后的干路，能同时控制全部支路。
- **非理想电源**：用理想电源与内阻串联表示，必要时用黑色虚线框将二者归为整体。`emf` 对应理想电源，`internal resistance` 对应内阻；`terminal voltage` 的括号或测量标注跨越整个电源的两个外部端子，不能只跨理想电源或内阻。标注线与导线应明显区分，不能形成额外电路连接。
- 正负极、开关状态、电流箭头及电压参考方向须相互一致。没有给出负载、电流或工作状态时，不添加未经限定的电压降公式或电流方向。

## 保存与交付

- 用户指定路径时按指定位置保存；否则默认保存到笔记库的 `附件/`，采用简短、能描述内容的 `.svg` 文件名。
- 新绘图不覆盖已有文件；用户要求修改某张图时只修改目标 SVG。绘图请求不自动嵌入或改写笔记正文，也不更改元件库、目录或配置。
- 根元素包含 SVG 命名空间、`width`、`height`、`viewBox`，并用 `role="img"`、`aria-labelledby` 关联唯一的 `<title>` 与 `<desc>`。描述说明电路结构、开关状态及必要的标注含义。
- 用 XML 解析器检查文件有效性，并核对元件数量、标签、端点连接、实际节点关系和标注范围。尤其检查是否意外短接、漏接，或将标注线当成导线。
- 检查符号和文字均位于 `viewBox` 内。环境已有可用的 SVG 渲染器时，预览并检查遮挡、裁切和文字位置；临时预览放在临时目录。未实际预览时不声称已验证渲染效果。
- 回复简短说明完成情况及必要的状态说明，提供 SVG 的可点击绝对路径；可用 Markdown 图片语法直接展示 SVG。无需粘贴全部源代码，不额外生成未要求的附件。
